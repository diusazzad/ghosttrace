## 3. Privacy & Checkpoint Protection Policy (TASK 03.4)

> [!IMPORTANT]
> **GhostTrace is a Public Open-Source Repository.**
> Unfiltered agent transcripts can inadvertently expose environment settings, prompt iterations, or sensitive paths. Entire CLI has been configured with strict privacy controls:

1. **`push_sessions: false` (Zero Public Checkpoint Push)**:
   - Configured in `.entire/settings.json`.
   - Automatic pushing of agent session transcripts and execution checkpoints to the public GitHub remote is **strictly disabled**.
   - All session checkpoints remain local to the development clone (`.entire/` metadata), preventing involuntary disclosure of raw session streams.
2. **Untracked Sensitive State**:
   - `.entire/.gitignore` excludes `tmp/`, `settings.local.json`, `metadata/`, `logs/`, and `redactors/local/`.
   - `.env.local`, API credentials (Auth0 secrets, MongoDB URIs, Backboard keys) are verified to remain uncommitted.

## 4. Installed Agent & Git Hooks

### A. Antigravity Agent Hooks (`.agents/hooks.json`)
The following 4 agent lifecycle hooks are configured to record agent activities:
1. **`SessionStart`**: Initializes session tracking when Antigravity starts an engineering turn.
2. **`PreInvocation`**: Tracks prompt invocations and context boundary updates.
3. **`PreToolUse`**: Captures file edits, command runs, and tool parameters.
4. **`Stop`**: Finalizes the agent turn and flushes session state.

### B. Git Lifecycle Hooks (`.git/hooks/`)
Configured with absolute executable pathing (`--absolute-git-hook-path`):
- `commit-msg`: Verifies commit trailers and formats checkpoint messages.
- `post-commit`: Condenses turn session data and anchors checkpoint SHA to the commit.
- `post-rewrite`: Preserves checkpoint links across rebase or amend operations.
- `pre-push`: Enforces session push restrictions (`push_sessions=false`).
- `prepare-commit-msg`: Injects `Entire-Checkpoint` trailer metadata into commit messages.
